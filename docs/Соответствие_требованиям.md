## 5. Автоматические проверки

Команда:

```powershell
python -m unittest discover -s tests -v
```

Результат:

```text
Ran 42 tests in 0.016s
OK
```

Проверяются:

* создание, выбор и удаление баз;
* дубликаты имён без учёта регистра;
* создание таблиц и полей, зарезервированное `id`;
* все четыре типа данных и их ошибки;
* пропущенные и лишние поля;
* `UPDATE` и `DELETE` по `id`;
* `ALTER TABLE ADD/DROP`;
* строки с запятыми и кавычками;
* незакрытые скобки;
* полный проход интерактивного урока;
* работа справки и демо-базы.

## 6. Выявленные ограничения

Это не ошибки, а осознанные рамки учебного проекта:

1. Нет сохранения на диск — требование задания.
2. Нет SQL-джойнов, транзакций и внешних ключей.
3. Изменение и удаление записи только по `id`.
4. Один пользователь, без сети.
5. Длинные значения в таблице сокращаются при выводе, но хранятся полностью.
